## Documentation Rules

Every document should distinguish between:

- IMPLEMENTED
- PARTIALLY IMPLEMENTED
- DESIGN
- PLANNED

Architecture documents describe intended system boundaries.

Implementation documents must describe the current code.

Roadmap documents describe future work.

Compliance documentation must distinguish between implemented controls and compliance objectives.

No documentation should claim certification, production deployment, or complete implementation without supporting evidence.
